# Les Crêpes de Beltrech19

Site web de la crêperie Beltrech19, permettant de consulter le menu, commander en ligne et installer l’application sur mobile (PWA).

## Fonctionnalités

- Consultation du menu crêpes & pancakes
- Ajout au panier et commande via WhatsApp
- Installation en tant qu’application mobile (PWA)
- Retrait ou livraison rapide

## Installation

1. Clone le dépôt ou télécharge les fichiers.
2. Place tous les fichiers dans un dossier sur ton serveur web.
3. Assure-toi que le site est servi en HTTPS pour activer la PWA.

## Structure des fichiers

- `index.html` : page principale
- `manifest.json` : configuration PWA
- `service-worker.js` : cache et fonctionnement hors-ligne
- `script.js` : logique JavaScript
- `style.css` : style du site (thèmes)
- `image/bel.jpg` : logo du site

## Installation sur mobile

- **Android/Chrome** : Un bouton "Installer l'app" apparaît si toutes les conditions PWA sont réunies.
- **iOS/Safari** : Utilise le menu "Partager" puis "Sur l’écran d’accueil".
